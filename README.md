# Honij

macOS · Windows 디스크 정리 + 파일 찾기 앱 **Honij** 의 홈페이지와 설치 파일 저장소입니다.

- 홈페이지: https://qkrwlsdh.github.io/honij-app/
- 설치 파일: [Releases](https://github.com/qkrwlsdh/honij-app/releases/latest)
- 문의 · 버그 신고: [Issues](https://github.com/qkrwlsdh/honij-app/issues)

**English** — This repository hosts the homepage and installers for Honij, a disk cleanup and file search app for macOS and Windows. Get the latest version from [Releases](https://github.com/qkrwlsdh/honij-app/releases/latest).

## 이 저장소의 구성

- `index.html` · `style.css` · `app.js` — 홈페이지(GitHub Pages, `main` 브랜치의 루트). 빌드 과정이 없는 정적 페이지입니다.
- 다운로드 버튼은 최신 Release 에 붙은 파일을 자동으로 가리키므로, 새 버전을 낼 때 페이지를 고치지 않아도 됩니다.
- 앱의 소스 코드는 이 저장소에 없습니다.
